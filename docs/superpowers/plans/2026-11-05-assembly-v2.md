2. **Deletion is total**: every §11 symbol has zero live references in a fresh census, and no test pins a deleted API (a law file guarding dead API is itself deleted — its protection must have a live-API successor or a recorded ruling).
3. **Boot law adjudication is a ruling, not a port**: `restore-only-boot-pass.ts` (assembly-only) vs the region `materialized_at` witness gets a written disposition with a red-first law reproducing the defect-4 receipt shape (cold boot → replay, zero fold).
4. **Quiescent writes cost zero**: memory/note write → region bytes unchanged, zero rotations, delta visible via volatile segment; growth backstop *requests* a fold, never re-renders the region.
5. **Re-assembly is census-gated**: no fringe file re-enters v2 without a named live caller in the current v2 tree; the census table is a committed artifact, and "not measured" is an admissible disposition only with a reopening trigger.
